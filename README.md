# 🎉 종강파티 실시간 투표

카훗처럼 큰 화면에 질문을 띄우고, 동기들이 휴대폰으로 답하면 질문이 끝날 때마다 결과가 바로 나오는 프로그램이에요. 정답은 없고 결과만 보여줘요.

- **객관식**: 보기 개수 제한 없음, 막대그래프
- **동기 고르기**: 동기 명단에서 검색해서 한 명 선택, 🥇🥈🥉 순위
- **숫자**: 평균 · 가장 많은 답 · 분포 그래프
- **단답(짧은 주관식)**: 같은 답끼리 자동으로 모아서(띄어쓰기, "교수님/교수" 차이 무시) 워드클라우드 + TOP 순위
- **메시지(긴 주관식)**: 익명 메모지로 화면에 공개, 클릭하면 크게 보기
- 모든 답은 **익명**이에요. 닉네임은 참여 인원 표시에만 쓰여요.

---

## 1. 준비 (한 번만)

1. **Node.js 설치**: https://nodejs.org 에서 **LTS** 버전을 받아 설치해요.
2. **동기 명단 넣기**: `roster.txt`를 열어 한 줄에 한 명씩 이름을 적어요. (진행자 화면의 ☰ 메뉴에서도 고칠 수 있어요.)
3. 질문을 바꾸고 싶으면 `questions.txt`를 고쳐요. (아래 "질문 고치기" 참고)

## 2. 실행

### 방법 A (추천) — 더블클릭 한 번
`시작하기.command`를 **더블클릭**해요.
- 처음에 "확인되지 않은 개발자" 경고가 뜨면: 파일을 **우클릭 → 열기 → 열기**.
- 터미널 창이 열리고 진행자 화면이 브라우저에 자동으로 떠요.
- 30초~1분 뒤 터미널에 `✅ 인터넷 참여 주소: https://xxxx.trycloudflare.com` 이 나오면 진행자 화면 QR에 자동으로 들어가요.
  → 동기들이 **와이파이가 달라도, LTE/5G로도** 들어올 수 있어요.
- 다른 창/기기에서 진행자 화면(`/host`)을 열면 비밀번호를 물어봐요. 터미널에 나온 **호스트 비밀번호**(숫자 4자리)를 넣으면 돼요.

### 방법 B — 터미널에서 직접
```bash
cd 다운받은/폴더/경로
node server.js --online     # 인터넷 주소까지 같이 (방법 A와 같음)
node server.js              # 같은 와이파이에서만 쓸 때
```
`--online` 없이 켜면 같은 와이파이에 연결된 휴대폰만 들어올 수 있어요. 학교/식당 와이파이는 기기끼리 연결을 막는 경우가 많아서 **`--online`을 추천**해요.
노트북을 휴대폰 핫스팟에 연결하고, 동기들도 같은 핫스팟에 붙는 방법도 있어요.

> 인터넷 주소가 안 만들어지면: `brew install cloudflared` 로 설치한 뒤, 서버를 켠 상태에서 새 터미널에
> `cloudflared tunnel --url http://localhost:3000` 을 실행하고, 나온 https 주소를 진행자 화면 ☰ 메뉴 → "참여 주소"에 붙여 넣어요.

## 3. 진행하는 법

1. 노트북을 프로젝터/TV에 연결하고 **진행자 화면**을 전체 화면으로(⌃⌘F) 띄워요.
2. 동기들이 QR을 찍고 닉네임을 넣어 입장해요. 입장한 사람이 화면에 떠요.
3. **첫 질문 시작 ▶** → 동기들이 휴대폰으로 답해요.
4. 제한시간이 끝나거나, 접속한 모두가 답하면 **자동으로 마감되고 결과가 나와요.** (기다리지 않고 바로 보려면 "마감하고 결과 보기")
5. **다음 질문 ▶** 반복. 키보드 **→ 화살표 / 스페이스**로도 넘어가요.

- `+15초`: 시간 연장
- `↻ 다시 받기`: 그 질문을 처음부터 다시
- `☰ 질문 목록 · 설정`: 아무 질문이나 골라서 시작, 지난 결과 다시 보기, 명단/질문/제한시간 수정, 초기화
- 메시지 메모지는 클릭하면 크게 보여요 (읽어주기 좋음).
- 서버를 껐다 켜도 답은 `data.json`에 남아 있어요. 새로 시작하려면 ☰ 메뉴 → 초기화.

## 4. 질문 고치기 (`questions.txt`)

한 줄에 질문 하나: `종류 | 질문 | 보기1, 보기2, ...`

| 종류 | 설명 | 예시 |
|---|---|---|
| 객관식 | 보기 중 하나 (개수 제한 없음) | `객관식 \| 실습조 선호도 \| 가나다, 칼리지, 랜덤, 학번` |
| 동기 | 동기 명단에서 한 명 | `동기 \| 다음 학기 과대는?` |
| 숫자 | 숫자로 답하기 | `숫자 \| 내가 알고 있는 동기 CC 개수는?` |
| 단답 | 짧은 주관식 (집계 + 워드클라우드) | `단답 \| 제일 좋은 교수님` |
| 메시지 | 긴 주관식 (익명 메모지) | `메시지 \| 22학번에게 하고 싶은 한마디` |

교수님·과목 이름 목록이 있으면 `단답` 대신 `객관식`으로 바꿔서 보기로 넣어도 돼요. 예) `객관식 | 제일 좋은 교수님 | 김OO, 이OO, 박OO, ...`
